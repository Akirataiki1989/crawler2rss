# crawler2RSS

Python scrapers write articles to PostgreSQL and generate RSS feeds. The NAS runs this project as a scheduled, one-shot Docker Compose job.

The Playwright Python package and base image must use the same version. HobbySearch uses Firefox.

## NAS deployment

Deploy the project to `/volume1/docker/crawler2rss`, keeping `runtime.env` on the NAS only. It contains `DATABASE_URL` and is loaded by python-dotenv. Compose overrides `RSS_OUTPUT_DIR` to `/rss`, mounted to `/volume1/docker/crawler2rss/rss`. The external `nas_network` must exist and provide the configured PostgreSQL hostname. Logs are stored in `logs/`.

Build with `docker compose build crawler`. DSM runs `run-scheduled.sh` at 08:00 and 20:00; its lock prevents overlapping runs. Each run creates a container and removes it after the job finishes. Running the job writes to the configured database and RSS directory. The application currently catches some individual scraper errors, so a zero exit code does not guarantee every source succeeded; inspect logs as well.

The repository is maintained in `/home/gui/projects/crawler2rss`; pushing to GitHub does not update the NAS. To deploy a change, copy the intended source files to the NAS deployment directory without overwriting `runtime.env`, rebuild the image, and verify the job before relying on the next schedule.

Do not commit `runtime.env`, RSS output, or logs. Keep the old deployment until the new job and schedule have been verified.

## Structured System Logs

Crawler2RSS can send operational events to the private NAS Logs API. It remains
safe when the API is unavailable: every event is first written to the dedicated
Docker named volume `crawler2rss_logs_spool` at
`/var/lib/log-spool/logs.sqlite`, then replayed in batches when delivery recovers.
The spool is capped at 300 MB or 100,000 events and evicts the oldest TRACE,
DEBUG, INFO, then WARNING records before it ever removes ERROR or CRITICAL.

Set the private `LOGS_INGEST_TOKEN` only in NAS `runtime.env`; never commit it.
Compose supplies the private Docker-network endpoint, service metadata, and
hostname `NAS`. Lifecycle events include crawler run start/complete/failure,
per-source start/failure/skipped, and the no-active-sources warning. Run the
transport tests with:

```bash
python -m unittest tests.test_logs_api
```

## Subscribe generated XML in FreshRSS

When FreshRSS runs on the NAS Docker network, subscribe to XML generated by this project with the internal URL beginning with `http://crawler-rss/`, for example:

```text
http://crawler-rss/mrjoe_newest.xml
```

Do not use the externally protected URL (`https://rss.akirataiki.com/feed/<filename>.xml`) inside FreshRSS. The external URL is intended for clients outside the Docker network and requires authentication.

## Simply Patrick

The `SimplyPatrick` source combines the site's `/posts/index.xml` and `/tils/index.xml` feeds. The first run imports the newest 50 entries; later runs import entries newer than the last saved URL. Both feeds must load successfully before any articles are saved. Article links serve as stable GUIDs, and the original feed's HTML content and publication dates are retained.

Register the source in `rss_feed.sources` with name `SimplyPatrick`, URL `https://blog.simplypatrick.com/`, RSS filename `simplypatrick.xml`, `is_active` true, and scraper class `scrapers.simplypatrick.SimplyPatrickScraper`. The output path on the NAS is `/volume1/docker/crawler2rss/rss/simplypatrick.xml`.

## MR.JOE latest products

The `MR.JOE_最新上架` source reads `https://store.mrjoe.com.tw/product/all/newest`. Its initial run imports at most 50 products; subsequent runs also fetch at most 50 new products. Each RSS item contains the product title and cover image, with the product detail URL as its stable GUID.

Register the source in `rss_feed.sources` with URL `https://store.mrjoe.com.tw/product/all/newest`, RSS filename `mrjoe_newest.xml`, `is_active` true, and scraper class `scrapers.mrjoe.MrJoeScraper`. On the NAS, the protected feed is available at `https://rss.akirataiki.com/feed/mrjoe_newest.xml`.
